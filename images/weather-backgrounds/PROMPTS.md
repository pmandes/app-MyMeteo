# Weather backgrounds

Generated with the built-in GPT Image tool on 2026-10-13. Each image is a separate
original generation, copied unchanged into the shared common module. The gradient remains
the fallback background. Both mobile and wearable products use these backgrounds.

## clear

Asset: [weather_bg_clear.png](../../common/src/main/resources/base/media/weather_bg_clear.png)

Use case: stylized-concept. Asset type: a production background bitmap for a mobile weather application, portrait 1024x1536. Create ONLY the background artwork, edge to edge, no device, no interface, no text, no icons, no logo. A quiet, elegant, very subtle atmospheric sky illustration behind translucent glass weather cards. Preserve this consistent app palette: light dusty pastel blue #DCE8F5 in the upper left fading diagonally to soft medium blue #3A77BA in the lower right. Low contrast, soft diffuse gradients, broad empty central area, faint weather details only near the edges, smooth refined raster painting, no busy texture, no harsh shadows, no saturated colors, no ground or buildings, no hard horizon. Weather cues should feel understated and realistic rather than cartoon symbols. Clear sunny weather: mostly open sky, a very faint warm ivory daylight glow from the upper left and two barely visible wisps of cloud near the edges. Keep the sun diffuse, without a distinct bright disc or rays.
